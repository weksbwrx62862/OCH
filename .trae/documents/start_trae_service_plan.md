  - `programmatic` TR-3.2：连接方法能够正常工作 - 已完成
- **结果**：
  - 方法 1：使用 Trae 客户端连接
    - 打开 Trae 客户端
    - 选择「远程连接」选项
    - 输入服务器 IP 地址
    - 输入连接令牌（从 `--connection-token-file` 指定的文件中获取）
    - 输入服务端口（从 `netstat` 命令输出中获取）
  - 方法 2：使用 VS Code 连接
    - 打开 VS Code
    - 安装 Trae 扩展
    - 使用扩展提供的远程连接功能
    - 输入服务器信息和连接令牌
  - 连接所需信息：
    - 服务器 IP 地址：远程 Linux 服务器的 IP
    - 服务端口：Trae 服务监听的端口（可通过 `netstat -tuln | grep LISTEN` 查看）
    - 连接令牌：从 `~/.trae-cn-server/.stable-{version}.token` 文件中读取
    - 工作目录：默认是 `/home/xxh`

  - 提供有效的解决方案
- **测试要求**：
  - `human-judgement` TR-4.1：问题覆盖全面 - 已完成
  - `human-judgement` TR-4.2：解决方案有效 - 已完成
- **结果**：
  - 常见问题 1：服务无法启动
    - 症状：执行启动命令后无响应或报错
    - 解决方案：
      - 检查端口是否被占用：`lsof -i :端口号`
      - 检查权限是否正确：`ls -la ~/.trae-cn-server/`
      - 检查日志文件：`cat ~/.trae-cn-server/manager-logs/{timestamp}/*.log`
  - 常见问题 2：无法连接到服务
    - 症状：客户端连接超时或拒绝连接
    - 解决方案：
      - 检查防火墙设置：`sudo ufw status`
      - 检查服务是否在监听：`netstat -tuln | grep LISTEN`
      - 检查连接令牌是否正确：`cat ~/.trae-cn-server/.stable-{version}.token`
  - 常见问题 3：服务启动后很快退出
    - 症状：服务启动后立即退出或几分钟后退出
    - 解决方案：
      - 检查系统资源：`free -m` 和 `top`
      - 检查日志文件中的错误信息
      - 确保 `--enable-remote-auto-shutdown` 参数设置正确
  - 常见问题 4：连接后功能受限
    - 症状：能够连接但某些功能不可用
    - 解决方案：
      - 检查网络连接是否稳定
      - 检查服务版本是否兼容
      - 重新启动服务：`pkill -f trae && 重新执行启动命令`
