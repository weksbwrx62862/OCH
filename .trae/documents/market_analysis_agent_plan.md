# 市场分析分配智能体实施计划

## 项目概述
创建一个智能体，用于自动分配市场分析任务给相应的技能模块。

---

## 功能目标

1. **市场分析任务识别**
   - 股票市场分析
   - 加密货币市场分析
   - 基金市场分析
   - 宏观经济分析
   - 技术分析
   - 风险评估

2. **任务分配逻辑**
   - 根据分析类型自动路由到对应技能
   - 支持多步骤任务分配
   - 整合多个技能的分析结果

3. **分析报告生成**
   - 综合多技能分析结果
   - 生成结构化报告
   - 提供投资建议

---

## 技能路由映射

| 分析类型 | 路由技能 | 触发词 |
|---------|----------|---------|
| 股票分析 | market-data, data-source, analysis | 股票、A股、港股、美股、股价 |
| 加密货币分析 | crypto-analysis, market-data | BTC、ETH、加密货币、比特币 |
| 基金分析 | fund-tracker, analysis | 基金、定投、净值 |
| 技术分析 | technical | RSI、MACD、布林带、K线 |
| 风险评估 | risk-assessor, portfolio | 风险、止损、压力测试 |
| 组合管理 | portfolio | 组合、持仓、再平衡 |
| 新闻分析 | news, finance-news-pro | 新闻、舆情、市场情绪 |
| 综合分析 | analysis, finance-assistant | 综合分析、投资建议 |

```
│   └── config.py            # 配置文件
└── README.md
```

---

## 核心功能模块

### 1. analyzer.py（主分析器）
- 接收用户分析请求
- 调用任务路由器
- 整合分析结果
- 调用报告生成器

### 2. task_router.py（任务路由器）
- 分析任务类型
- 路由到对应技能
- 管理多步骤任务
- 处理降级方案

### 3. report_generator.py（报告生成器）
- 格式化分析结果
- 生成结构化报告
- 提供可视化建议
- 输出Markdown格式报告
