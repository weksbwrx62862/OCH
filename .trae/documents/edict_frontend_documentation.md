# Edict 前端访问文档

## 1. 前端访问地址

✅ **Edict 前端访问地址**: http://localhost:7891

**服务器状态**: 运行中
**端口**: 7891
**绑定地址**: localhost (127.0.0.1)

## 2. 服务器管理

### 2.1 启动服务器

**方法一: 后台运行**
```bash
# 切换到 dashboard 目录
cd /home/xxh/edict/dashboard

# 启动服务器（后台运行）
python3 server.py --port 7891 &
```

**方法二: 前台运行（开发模式）**
```bash
# 切换到 dashboard 目录
cd /home/xxh/edict/dashboard

# 启动服务器（前台运行）
python3 server.py --port 7891
# 按 Ctrl+C 停止
```

### 2.2 停止服务器

**方法一: 使用进程 ID**
```bash
# 查找服务器进程
ps aux | grep server.py

# 终止进程
kill <进程ID>
```

**方法二: 使用端口**
```bash
# 查找占用端口 7891 的进程
lsof -i :7891

# 终止进程
kill <进程ID>
```

## 3. 前端功能

### 3.1 核心功能模块
- **任务看板**: 查看和管理所有任务
- **部门管理**: 查看各部门状态和绩效
- **Agent 状态**: 监控各 Agent 的运行状态
- **实时数据**: 查看系统实时运行数据
- **技能管理**: 管理各部门的技能

### 3.2 API 接口

| 接口地址 | 方法 | 功能描述 |
|---------|------|----------|
| `/api/live-status` | GET | 获取实时状态数据，包含任务、部门、绩效等信息 |
| `/api/agent-config` | GET | 获取 Agent 配置信息，包含各部门配置和技能 |
| `/api/set-model` | POST | 设置 Agent 的模型 |
| `/api/model-change-log` | GET | 获取模型变更日志 |
| `/api/last-result` | GET | 获取上次模型变更结果 |

### 3.3 前端页面
- **首页**: http://localhost:7891 (dashboard.html)
- **静态资源**: 位于 `dist` 目录
- **响应式设计**: 支持不同设备访问

## 4. 访问注意事项

### 4.1 系统要求
- **浏览器**: 推荐使用 Chrome、Firefox、Edge 等现代浏览器
- **网络**: 本地网络访问，无需互联网连接
- **权限**: 无需特殊权限，本地访问即可

### 4.2 常见问题

**问题**: 无法访问前端页面
**解决方法**:
1. 确认服务器是否运行: `ps aux | grep server.py`
2. 确认端口是否可用: `curl http://localhost:7891`
3. 重启服务器: `cd /home/xxh/edict/dashboard && python3 server.py --port 7891 &`

**问题**: API 接口返回错误
**解决方法**:
1. 检查服务器日志: 查看服务器输出
2. 确认数据文件存在: 检查 `data` 目录下的 JSON 文件
3. 重启服务器以重新加载数据

### 4.3 性能优化
- **页面加载**: 首次加载可能需要几秒钟，之后会缓存
- **数据更新**: 实时数据每 30 秒自动更新
- **资源使用**: 服务器资源占用较低，适合长期运行
