#### 修复 4：验证自动降级机制

**问题**：

- 需要确保降级过程对用户透明

**解决方案**：
- try-except 包装 MX API 调用
- MX 失败时自动调用 AkShare 版本
- 显示数据源信息，让用户知道当前使用的数据源

**代码逻辑**（china.py 第 181-208 行）：
```python
def get_north_flow():
    """北向资金（最新实时数据 - 优先 MX API）"""
    try:
        print("=" * 60)
        print("📊 北向资金流向（最新）")
        print("=" * 60)
        
        if mx_client and mx_client.available:
            try:
                mx_tables, source = get_north_flow_mx()
                if mx_tables:
                    print_data_source(source)
                    print_north_flow_from_mx(mx_tables)
                    print("\n" + "=" * 60)
                    return
            except Exception as e:
                print(f"⚠️  MX API 查询失败: {e}")
                print("   正在降级到 AkShare...")
        
        # 降级到 AkShare
        df, source = get_north_flow_akshare()
        print_data_source(source)
        print_north_flow_from_akshare(df)
        print("\n" + "=" * 60)
```

**结果**：
- ✅ 自动降级机制正常
- ✅ MX 失败时透明切换到 AkShare
