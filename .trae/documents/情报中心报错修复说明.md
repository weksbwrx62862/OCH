## 修复方案

### 方案一：复制文件到 Vault 目录（推荐）

将 `/home/xxh/obsidian_integration.py` 复制到 `/media/xxh/APP/KN/`。

```python
# 通过 execute_code 工具执行
import shutil
from pathlib import Path

source = Path("/home/xxh/obsidian_integration.py")
target = Path("/media/xxh/APP/KN/obsidian_integration.py")

if source.exists():
    shutil.copy2(source, target)
    print(f"✅ 文件已复制: {target}")
else:
    print(f"❌ 源文件不存在: {source}")
```

### 方案二：创建符号链接

```python
import os
from pathlib import Path

source = Path("/home/xxh/obsidian_integration.py")
target = Path("/media/xxh/APP/KN/obsidian_integration.py")

if source.exists():
    if target.exists():
        target.unlink()
    os.symlink(source, target)
    print(f"✅ 符号链接已创建: {target} -> {source}")
```
