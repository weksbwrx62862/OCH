## `obsidian_integration.py` 搜索功能详解

### 核心函数：`search_notes(query, directory, tag)`

**位置**：`obsidian_integration.py:203-253`

**功能**：
- 支持纯文本关键词匹配 (`query`)
- 支持标签匹配 (`tag`)
- 支持指定目录搜索 (`directory`)
- 默认搜索整个 Vault（`VAULT_PATH`）

**搜索逻辑**：
1. 遍历所有 `.md` 文件
2. 忽略隐藏文件和 `_MOC.md` 索引文件
3. 使用 `frontmatter` 解析 YAML 前置元数据
4. 检查标签匹配（如果指定了 `tag`）
5. 检查关键词匹配：
   - 标题匹配：`query_lower in title.lower()`
   - 内容匹配：`query_lower in content.lower()`
6. 返回前 200 字符预览
7. 最多返回 `CONFIG["searchLimit"]` 条结果（默认 10 条）

**返回结果格式**：
```python
{
    "title": "笔记标题",
    "path": "相对路径",
    "preview": "前200字符...",
    "tags": ["标签1", "标签2"]
}
```

### 命令行调用方式

**位置**：`obsidian_integration.py:547-568`

```bash
# 基本搜索
python3 /home/xxh/obsidian_integration.py search "关键词"

# 指定目录搜索

# 组合使用

```
