# 免费金融技能系统整合计划 v3

## 目标

构建一个**功能完整、100%免费、稳定可靠**的金融技能系统，替代所有依赖付费API的技能。

## 免费数据源体系

| 数据源 | 覆盖范围 | 数据类型 |
|--------|----------|----------|
| AkShare | A股 | 行情、财务、资金流向、宏观、选股 |
| yfinance | 美股/港股 | 报价、历史数据、基本面 |
| ExchangeRate-API | 外汇 | 汇率 |
| 东方财富(网页) | 资讯 | 财经新闻、公告 |
| LLM (本地) | 分析 | 财报分析、报告生成 |

## 技能详细设计

### 1. china-stock (AkShare A股)

**核心功能**：
```python
import akshare as ak

# 实时行情
ak.stock_zh_a_spot_em()  # A股实时行情

# 财务指标
ak.stock_financial_analysis_indicator()  # ROE、净利润等

# 资金流向
ak.stock_individual_fund_flow()  # 个股资金流向

# 宏观数据
ak.macro_china_gdp()  # GDP
ak.macro_china_cpi()  # CPI
```

**触发词**：A股行情、查股价、资金流向、宏观数据

### 2. us-stock (yfinance 美股)

**核心功能**：
```python
import yfinance as yf

ticker = yf.Ticker("AAPL")
info = ticker.info  # 基本面
hist = ticker.history(period="1y")  # 历史
financials = ticker.financials  # 利润表
```

**触发词**：美股行情、苹果股价、英伟达

### 3. forex (外汇)

```python
import requests
```

**核心功能**：
