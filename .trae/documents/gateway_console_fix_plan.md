# OpenClaw 网关控制台链接问题 - 解决方案

## [ ] 任务 1: 检查当前配置文件
- **优先级**: P0
- **依赖**: 无
- **描述**: 
  - 查看 `~/.openclaw/openclaw.json` 配置文件中的网关认证令牌配置
  - 确认 `gateway.auth.token` 和 `gateway.remote.token` 是否存在且匹配
- **成功标准**: 确认配置文件中的令牌配置情况
- **测试要求**: 
  - `programmatic` TR-1.1: 能够读取配置文件并查看令牌配置
  - `human-judgement` TR-1.2: 确认配置文件结构正确，令牌值存在

## [ ] 任务 2: 检查网关服务状态
- **优先级**: P0
- **依赖**: 任务 1
- **描述**: 
  - 检查网关服务是否正在运行
  - 查看服务日志，了解可能的错误信息
- **成功标准**: 确认网关服务的运行状态
- **测试要求**: 
  - `programmatic` TR-2.1: 服务状态为运行中
  - `human-judgement` TR-2.2: 日志中无严重错误

## [ ] 任务 3: 修复令牌配置
- **优先级**: P0
- **依赖**: 任务 1, 任务 2
- **描述**: 
  - 如果令牌缺失或不匹配，更新配置文件
  - 确保 `gateway.auth.token` 和 `gateway.remote.token` 相同
  - 重启网关服务使配置生效
- **成功标准**: 配置文件中的令牌配置正确，服务重启成功
- **测试要求**: 
  - `programmatic` TR-3.1: 配置文件中令牌值正确设置
  - `programmatic` TR-3.2: 服务重启后运行正常

## [ ] 任务 4: 验证网关控制台链接
- **优先级**: P0
- **依赖**: 任务 3
- **描述**: 
  - 打开网关控制台 URL，检查是否可以正常链接
  - 验证认证是否成功，无令牌错误
- **成功标准**:
