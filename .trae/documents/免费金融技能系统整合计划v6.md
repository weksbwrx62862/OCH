# 免费金融技能系统整合计划 v6

## 目标

构建一个**功能完整、100%免费、稳定可靠**的金融技能系统。

## 优化后的技能架构

### 核心理念
- **减少技能数量**：将功能相近的合并
- **统一入口**：一个技能处理所有金融需求
- **模块化设计**：每个脚本独立可调用

## 技能详细设计

### 1. finance-assistant (统一入口) ⭐核心

**职责**：智能路由，理解用户意图

```python
def assistant(query: str):
    """统一金融助手"""
    intent = recognize_intent(query)

    if intent == "quote":
        return market_data.get_quote(query)
    elif intent == "technical":
        return technical.analyze(query)
    elif intent == "news":
        return news.get_news(query)
    elif intent == "portfolio":
        return portfolio.analyze(query)
    elif intent == "report":
        return analysis.generate_report(query)
    else:
        return mixed_analysis(query)
```

**触发词**：
- "查询贵州茅台"
- "帮我分析技术面"
- "今天的财经新闻"
- "我的投资组合"
- "生成深度报告"
