## 发现的问题与建议

### 1. 环境不一致
- **问题**: Terminal 6 有虚拟环境，Terminal 8 没有
- **影响**: 在不同终端运行脚本可能失败
- **建议**: 统一使用虚拟环境或安装到系统 Python

### 2. 导入检查过于严格
- **问题**: 部分 `try/except ImportError` 逻辑误报
- **建议**: 更新导入检查方式，使用更宽松的检查

### 3. yfinance 限流问题
- **现象**: 多个脚本因 Yahoo API 限流而超时
- **已实现**: cache.py 缓存机制可缓解此问题
- **建议**: 所有 yfinance 调用应使用 YFCache 封装

### 4. AkShare 网络不稳定
- **现象**: A股相关脚本经常连接超时
- **原因**: 东方财富数据源网络波动
- **建议**: 增加重试机制和备用数据源
