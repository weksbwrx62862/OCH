## 技能详细功能

### 1. china-stock (A股综合)

**数据源**: AkShare + 非凸科技

**核心功能**：
```python
# 实时行情
akshare.stock_zh_a_spot_em()

# 财务数据
akshare.stock_financial_analysis_indicator()

# 资金流向
akshare.stock_individual_fund_flow()

# 龙虎榜
akshare.stock_lhb_detail_em()

# 融资融券
akshare.stock_margin_detail_sz()

# IPO
akshare.stock_ipo_summary_cninfo()

# 宏观
akshare.macro_china_gdp()
akshare.macro_china_cpi()
```

**触发词**：A股、沪深、查股价、资金流向、龙虎榜

### 2. global-stock (全球股票) ⭐新

**数据源**: yfinance

**核心功能**：
```python
# 港股
ticker = yf.Ticker("0700.HK")  # 腾讯

# 美股
ticker = yf.Ticker("AAPL")

# 日股
ticker = yf.Ticker("7203.T")  # 丰田

# 欧股
ticker = yf.Ticker("SAP.DE")  # 德国
```

**触发词**：港股行情、腾讯股价、美股、日股、欧股

### 3. forex (外汇)

**数据源**: ExchangeRate-API

**核心功能**：
```python
import requests
resp = requests.get("https://open.er-api.com/v6/latest/USD")
rates = resp.json()["rates"]
# rates["CNY"] 人民币
# rates["EUR"] 欧元
# rates["JPY"] 日元
```

**触发词**：美元汇率、欧元走势、换汇

### 4. commodities (大宗商品) ⭐新

**数据源**: yfinance

**核心功能**：

```python
# 铜

```

**触发词**：黄金价格、原油走势、白银、铜价

### 5. crypto (加密货币) ⭐新
