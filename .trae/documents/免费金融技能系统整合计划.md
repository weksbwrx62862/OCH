## 各技能详细设计

### 1. china-stock (AkShare A股)

**核心功能**：
```python

# 财务数据
akshare.stock_financial_analysis_indicator()  # 财务指标

# 资金流向
akshare.stock_individual_fund_flow()  # 个股资金流向

# 宏观数据
akshare.macro_china_gdp()  # GDP
akshare.macro_china_cpi()  # CPI

# 选股
```

## 整合策略

### 统一入口 (finance-assistant)

创建 `finance-assistant` 作为统一入口：
- 理解用户意图
- 自动路由到对应技能
- 整合多技能结果

```python
def finance_assistant(query: str):
    """统一金融助手"""
    if "A股" in query or "沪深" in query:
        return china_stock(query)
    elif "美股" in query or "港股" in query:
        return us_stock(query)
    elif "汇率" in query or "外汇" in query:
        return forex(query)
    elif "新闻" in query or "快讯" in query:
        return finance_news(query)
    elif "选股" in query:
        return stock_screener(query)
    else:
        return mixed_assistant(query)  # LLM综合分析
```

1. **缓存机制**: 热门数据缓存5分钟
2. **错误重试**: 请求失败自动重试3次
3. **多源备份**: 主数据源失败时切换备份
4. **限流控制**: 避免触发API限制
